# Размер

Веб-редактор размерных стрелок поверх изображений. Подписи вычисляются по заданному масштабу или редактируются вручную. Изображения обрабатываются только в браузере, без отправки на сервер. Аккаунт, API-ключи и внешние библиотеки не нужны.
Данный проект нужен был для измерения пыльцы на снимках с микроскопа.

## Возможности

- Загрузка PNG, JPEG, WebP, GIF и BMP, включая drag-and-drop.
- Рисование, перемещение, дублирование и удаление стрелок.
- Настройка выносок, линий, цвета, шрифта, размера и шести уровней толщины текста.
- Масштаб в пикселях или сантиметрах с указанным DPI; калибровка по известному отрезку.
- Автоматические размеры и ручные подписи; отдельное перемещение текста.
- Зум и перемещение увеличенного изображения мышью.
- Независимо сворачиваемые разделы, отмена и повтор действий.
- Настраиваемые горячие клавиши с сохранением в браузере.
- Экспорт PNG и текущих подписей в числовую колонку CSV.

## Запуск

Нужен Node.js 22 или новее и современный браузер. Из каталога проекта:

```sh
npm start
```

Откройте http://127.0.0.1:5173. Остановка сервера — Ctrl+C. Альтернативная команда: `node server.cjs`.

Установка зависимостей и сборка не требуются. Открывайте приложение через HTTP-сервер, а не двойным щелчком по HTML: оно использует JavaScript-модули. Локальный сервер слушает только 127.0.0.1 и предназначен для разработки.

## Работа с изображением

1. Загрузите изображение.
2. В разделе «Масштаб изображения» задайте соответствие, например **200 px = 100 µm**. Или укажите известную длину в поле «Соответствует», нажмите «Задать по отрезку» и проведите этот отрезок на изображении.
3. Проведите размерную стрелку, удерживая левую кнопку мыши. Shift фиксирует горизонталь или вертикаль.
4. Выберите стрелку: круги перемещают концы отрезка, ромб меняет выноску. Стрелку и подпись можно перетаскивать отдельно. Координаты концов доступны в разделе положения.
5. Для ручной подписи выключите «Рассчитывать размер автоматически».
6. При увеличении перетаскивайте изображение **зажатой правой кнопкой мыши (ПКМ)**. Контекстное меню над рабочим полем отключено при загруженном изображении. Координаты стрелок остаются прежними. Перемещение ограничено краями прокручиваемого рабочего поля.
7. Сохраните результат кнопками «Скачать PNG» и «Скачать CSV».

### Масштаб и точность

Начальное значение — **1 см = 100 µm при 96 DPI**. Это предположение, а не определение масштаба фотографии. Для сантиметров укажите DPI исходного изображения; физический размер экрана не используется. Если DPI неизвестен, выбирайте пиксели или калибровочный отрезок.

Единица по умолчанию — µm, можно задать любую. Переименование единицы не выполняет перевод величин: укажите соответствующее числовое значение масштаба в новой единице. Изменение масштаба пересчитывает автоматические подписи, сохраняя ручные. Зум и выноски не влияют на измеренную длину.

Масштаб сохраняется при загрузке другого изображения в текущей вкладке — проверьте его перед измерением. Геометрия, размеры текста и толщина линий заданы в пикселях исходного изображения.

### Экспорт

**PNG:** исходное разрешение, стрелки без маркеров выделения. Всё за границами изображения обрезается. Дополнительные уровни толщины текста формируются утолщением контуров символов и сохраняются при экспорте.

**CSV:** одна колонка без заголовка и единиц, в порядке создания стрелок. Используются числа из **текущих подписей**, включая ручные изменения и видимое округление. Пример: `123,50 µm` → `123.50`. Десятичный разделитель — точка. Если в подписи нет числа или несколько чисел, приложение сообщает номер стрелки для исправления. При импорте в таблицы при необходимости укажите точку как десятичный разделитель.

## Горячие клавиши

| Действие | По умолчанию |
| --- | --- |
| Новая стрелка | A |
| Выделение | V |
| Калибровка | C |
| Вписать изображение | F |
| Перемещение изображения | Перетаскивание зажатой правой кнопкой мыши |
| Увеличение / уменьшение | Z + колесо мыши |
| Удалить стрелку | Delete |
| Дублировать | Ctrl / Cmd + D |
| Отменить | Ctrl / Cmd + Z |
| Повторить | Ctrl / Cmd + Shift + Z |
| Горизонталь / вертикаль при рисовании | Shift |
| Отменить рисование / снять выделение / закрыть окно | Escape |

Кнопка «Хоткеи» открывает настройки: нажмите сочетание, введите новое и сохраните. Назначения привязаны к расположению клавиш и работают при русской раскладке. Во время ввода текста и в окне настроек действия редактора не запускаются. Shift и Escape выполняют фиксированные вспомогательные действия. Ранее сохранённое назначение клавиши для перемещения больше не используется; остальные назначения сохраняются. Перемещение ПКМ — фиксированное действие мыши.

## Ограничения и хранение данных

- До 30 МБ, 40 Мп и 16 000 пикселей по стороне.
- Для GIF используется неподвижный кадр.
- Изображение и разметка хранятся в памяти вкладки. Обновление страницы или новое изображение очищает разметку. Перед этим экспортируйте результат.
- В localStorage сохраняются только настройки горячих клавиш.
- В поддерживающих WebMCP браузерах доступны `read_dimensions` и `add_dimension`.

## Структура проекта

```text
dist/                 # Исходники, готовые к статическому размещению
  index.html          # Интерфейс
  style.css           # Стили
  app.js              # Редактор, взаимодействие и экспорт
  measurement.mjs     # Расчёт и форматирование измерений
server.cjs            # Локальный HTTP-сервер
tests/                # Проверки расчётов и сценариев редактора
```

## Проверки

```sh
npm run check
npm test
```

Без npm:

```sh
node --check dist/app.js
node --check dist/measurement.mjs
node --check server.cjs
node --test tests/measurement.test.mjs tests/editor.test.mjs
```

Проверяются масштаб, CSV, редактирование стрелок, отмена, толщина текста, хоткеи, зум и перемещение. Тесты редактора используют моделируемые события и Canvas; они не заменяют визуальную проверку. GitHub Actions запускает проверки при push и pull request.

## Статический хостинг

Размещайте содержимое `dist/`: серверная логика и сборка не нужны. Относительные пути позволяют размещать приложение в подкаталоге. Для GitHub Pages публикуйте содержимое `dist/` как статический артефакт; `server.cjs` для этого не нужен. Автоматическая публикация сайта в этом репозитории не настроена.
